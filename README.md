# EVO Afterdark

Dark VS Code / Kiro color themes built on deep cosmic blacks with electric cyan, ultraviolet and neon magenta accents. Syntax text stays calm and legible; the neon is reserved for keywords, functions, operators, tags and UI focus states.

| Theme | Editor | Cyan | Ultraviolet | Magenta | Foreground |
| --- | --- | --- | --- | --- | --- |
| **EVO \| Neon** (flagship) | `#0B1020` | `#36E6F6` | `#B78CFF` | `#FF5DBC` | `#DCE7F7` |
| **EVO \| Void** (darker, flat) | `#080B14` | `#2CD9F1` | `#AE89FF` | `#F76DBB` | `#D6E2F3` |

Both themes keep the full TextMate scope coverage of the original Evro Dark themes (233 rules each), enable semantic highlighting, and style the editor, tabs, explorer, command palette, panels, integrated terminal (including ANSI colors), Git decorations and diffs, and the chat surfaces exposed through VS Code color keys.

## Install from a local VSIX

```sh
npm install
npm test
npm run package
```

`npm run package` writes `evo-afterdark-<version>.vsix` to the repository root. Install it with **Extensions: Install from VSIX...**, or from a terminal:

```sh
code --install-extension /absolute/path/to/evo-afterdark-1.0.0.vsix
# Kiro IDE on macOS:
/Applications/Kiro.app/Contents/Resources/app/bin/code --install-extension /absolute/path/to/evo-afterdark-1.0.0.vsix
```

Then run **Preferences: Color Theme** and choose **EVO | Neon** or **EVO | Void**, or set it per workspace:

```json
"workbench.colorTheme": "EVO | Neon"
```

## Development

- `themes/evo-neon-color-theme.json` and `themes/evo-void-color-theme.json` are generated by `npm run build` (`scripts/build-themes.js`) from the original Evro themes in `themes/EvroDark.json` and `themes/EvroDarkerFlat.json`. Edit the palettes in the script, not the generated files.
- `npm test` (`scripts/validate-themes.js`) checks the manifest, JSON validity, theme paths, the preserved TextMate rules and the semantic token coverage.
